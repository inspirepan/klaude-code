Search the web for up-to-date information beyond your knowledge cutoff. Returns title, URL, and snippet for each result; some providers also return a generated answer with citations.

Snippets are short excerpts, not page content. To read a result in full, pass its URL to `WebFetch`. Write the query as you would type it into a search engine, and include the year or version when recency matters. Use it for facts that may have changed or that the workspace cannot answer; do not use it for questions about local code.
