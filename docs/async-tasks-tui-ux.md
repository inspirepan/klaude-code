# 异步任务 TUI：交互设计与验收

> 本文描述本轮 UX 目标；验收结果在实现和 review 完成后补充。

## 主对话与后台工作是两个独立状态

- 普通输入始终发送到当前主会话，不因为任务选择或查看结果而改变收件人。
- 主会话的工作、等待、暂停和可输入状态，不等于子任务的运行状态。
- 后台子任务继续运行时，保留可见状态和管理入口，不把主会话显示成全部工作已完成。
- Esc 停主会话的当前推理或等待；`/stop` 停当前会话的全部子 agent，不停止独立 Bash。

| 场景 | 应表达的含义 | 用户可以做什么 |
| --- | --- | --- |
| 主会话运行，child 运行 | 主会话正在处理，后台工作独立继续 | 发送 steering、打开任务面板、中断主会话 |
| 主会话等待 task | 正在等待明确任务，而非模型仍在推理 | 查看任务、发送 steering、解除当前等待 |
| 主会话正常结束，child 运行 | 主会话可继续输入，但后台仍在工作 | 继续主对话、管理或停止后台子任务 |
| 主会话被 Esc 暂停，child 运行 | 只暂停了主会话，child 没有停止 | 继续主对话、`/stop` 停子 agent |
| child 等授权或回答 | 任务需要人处理，不是假装仍在正常执行 | 使用既有授权/问答界面 |
| child 已完成或失败 | 活动计数减少，结果仍可找回 | 在任务面板查看结果或失败信息 |
| 只有后台 Bash | 命令仍在运行，主会话可用 | 查看或停止具体命令；不提示 `/stop` 能停 Bash |

## 默认底部只放决策需要的信息

- 任务描述优先，其次是真实状态、耗时和必要的最近活动。
- compact 模式弱化模型、token 和工具数量；expanded 保留诊断细节。
- 待处理交互、失败优先于普通活动；同优先级保持稳定排序，避免行不断换位。
- 默认最多展示少量子任务，额外任务使用数量与 `/tasks` 入口提示。
- 小终端仍保留输入区；任务内容折叠或截断，不让完整 ID 和日志挤走输入。
- 保持现有 status sink、prompt-toolkit 布局和 event tape，不增加动画或独立 stdin reader。

## 任务面板用于操作，转录展开用于阅读

- 无参数 `/tasks` 打开交互面板，显式 `/tasks list/output/wait/stop` 保留旧语法。
- 方向键选择、Enter 打开任务操作；Esc 返回或关闭，不触发主会话 interrupt。
- 以任务名称和状态选择目标，完整 ID 放在详情，而不是要求用户先复制 ID。
- 面板提供结果、分页、刷新和可执行的单任务操作；停止结果必须来自真实回执。
- 运行中 agent 的发送消息动作需明确显示所选收件人，并在确认后发送；普通主输入路由不改变。
- Bash、终态、排队和停止中的任务不提供发消息动作；终态不提供无意义的停止动作。
- 消息针对当前运行 operation 校验，不能因为任务在选择后结束而启动不属于原任务的新轮次；旧服务不支持安全接口时拒绝发送。
- 面板打开时执行继续；关闭保留编辑草稿与光标，不能恢复陈旧草稿覆盖新内容。
- 授权与任务面板共用输入所有权，不能并发启动两个终端应用争抢键盘。
- 面板的查询与刷新不在转录中反复打印列表，也不启动模型。

## ManageTasks 使用专用工具视图

- 工具调用沿用现有工具树缩进与 `Tasks` 身份，不展示原始参数 JSON。
- 查询结果展示活跃、终态、失败数量；名称和 Agent/Bash 状态分列，状态不被长名称挤掉。
- compact 只显示有限行，并优先保留失败；expanded 保留完整任务 ID、child session 和 Bash 日志路径。
- 输出保持专用正文区，保留分页 offset 和可执行的下一页命令。
- 等待被打断只表示结束当前等待，不表示任务被停止；停止结果展示服务实际状态。
- 错误、取消和格式不完整的返回也走专用反馈，不退回通用工具卡片。

## 结果可查看不等于用户未读

- `delivered` 表示结果是否已交付模型，不表示人是否已经看过。
- 本轮保留完成/失败结果的访问入口，不根据 `delivered` 制造人类未读计数。
- 查看结果、读取分页或 CLI/TUI 查询都不确认主 agent 已收到完整结果。
- 结果完成不需要额外唤醒主 agent，只为解释“已经完成”而生成一次助手答复。
- peer 正文、任务报告和操作者输入保留不同来源，消息不代替权限批准。

## 验收覆盖

- 主结束或暂停后，child 仍可见；重新发送主输入后，主状态正确恢复。
- 多任务、授权、失败、终态、重连与 Ctrl+O/刷新都保持一致身份和排序。
- 任务面板忙时可打开，Esc 不中断 root，不丢草稿；授权弹窗不会与它争抢输入。
- 正确目标的结果分页、单任务停止、agent 消息发送和失败反馈。
- 80x24、60x20 等有限尺寸下，任务区折叠且输入仍可用。
- 完成结果可以找回，查看不等于交付确认，不增加助手收尾或模型调用。
